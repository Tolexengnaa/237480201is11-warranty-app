# LỚP GIAO DIỆN (Web UI)

Ba màn hình theo wireframe (`docs/wireframe.png`): **M1** Tạo phiếu bảo hành · **M2** Danh sách phiếu bảo hành · **M3** Chi tiết phiếu bảo hành.
